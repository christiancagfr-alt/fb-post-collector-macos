FB 贴文数据采集 v1.4.18 — Windows / macOS

发布位置：christiancagfr-alt/fb-post-collector-macos（个人账号，不上传组织仓库）。
Apple Silicon 选 arm64.dmg；Intel 选 x86_64.dmg。要求 macOS 15 或以上。
Windows 64 位请选择 Setup.exe 或 MSI 安装包；ZIP 为解压运行版。
安装包由本仓库 GitHub Actions 构建、验证并上传，随附 SHA256 和构建证明。

本次更新：
- API 密钥、Google 授权及 Drive token 使用系统钥匙串保护的认证加密；旧明文数据在启动时迁移。
- 修复跨站请求/Host 边界、表格公式注入、媒体下载与授权配置来源验证问题。
- 更新依赖、固定组件直接下载版本和摘要；加强更新包完整性验证。
- 本 Mac 版本检查更新改用当前个人仓库。
- 随包提供中文功能说明，安全审核报告仅在开发者本地保存。

重要：升级前退出软件并妥善备份数据。请用原电脑、原系统账号启动；不要让旧版程序直接读取已迁移的加密数据。跨电脑请导入项目配置并重新授权。
未使用 Apple Developer ID 签名/公证，首次打开可能被 macOS 阻止；不要全局关闭系统安全防护。
真实 Facebook/Google 账号端到端采集和真实用户钥匙串迁移尚未完成验收。
运行时升级、平台间接依赖锁定仍有后续工作；这不是“零风险认证”。
已知并发音频读取存在任务间混淆风险，处理音频时建议先使用 1 路执行，等待后续修复。

主程序包含 Python。先安装 Google Chrome；OCR/音视频组件按需安装，Mac 需要 Homebrew。
Windows 和 Mac 安装包均发布到当前个人仓库，不变更组织仓库中的既有发布。
