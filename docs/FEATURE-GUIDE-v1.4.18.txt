FB 贴文数据采集 — macOS v1.4.18 功能与操作说明
日期：2026-10-02

一、用途与限制
读取你有权访问的 Facebook 贴文链接，处理图片、OCR、音频及翻译，按配置写回 Google Sheets。不是 Facebook 官方工具；页面变化、账号权限、网络和配额都会影响结果，不保证每项数据都能获取。请遵守平台规则和数据使用权限。

二、下载安装
发布地址：https://github.com/christiancagfr-alt/fb-post-collector-macos/releases
M 系列 Apple 芯片选择 arm64.dmg，Intel 选择 x86_64.dmg；要求 macOS 15 或更高。
打开 DMG，将应用拖入 Applications 后启动。主程序包含 Python，不需要另行安装 Python；独立语音组件仍需准备自己的运行环境。
请先安装 Google Chrome；按 https://brew.sh 官方说明准备 Homebrew，再在环境检测页按需安装 OCR/音视频组件。
未进行 Apple Developer ID 签名和公证。首次打开可能被 macOS 阻止，核实来源后按系统提供的单个应用授权方式处理，不要全局关闭系统防护。
软件自动打开本地管理页面，默认 http://127.0.0.1:5199/，以实际显示地址为准。关闭网页不等于退出，退出请使用菜单栏图标。

三、首次配置
1. 环境检测：查看 Chrome、Tesseract、语言包、FFmpeg、Whisper、yt-dlp 状态，安装缺失项，查看日志后重新检测。下载完成不等于安装成功；校验失败不能跳过。
2. 授权设置：使用自己的 Google 客户端配置完成 Sheets 授权，或按界面支持的服务账号方式配置。表格须允许相应账号访问。
3. 浏览器账号：为 Facebook 账号添加独立配置，打开专用 Chrome 手动登录，返回检查状态。头像/状态可能有延迟，不保证永远在线。
4. Google Drive 账号：按页面配置客户端及授权，项目选择 Drive 图片上传方案。多个账号可参与上传调度，但全部无空间/授权失败时仍会报错。
5. 新建项目：指定表格、工作表、链接列、行范围、账号与字段映射，先用少量行验证。

四、项目、字段配置与多人分工
可配置表头行、开始行、结束行、写入开始列、抓取日志列和每个字段的写入列；字段可启用、排序、导入和导出。
开始/结束行都是表格真实行号，包含两端。结束行为 0/留空时按界面约定执行到末尾。
三人分工示例：2–101 行、102–201 行、202–301 行。不同电脑没有分布式锁，不重叠区间才可避免互相覆盖。
项目列表可导出项目，别人导入后重新核对表格权限、账号绑定和列映射。项目导出不是完整备份，不包含 API 密钥、Google token、浏览器会话或系统加密主密钥。

五、采集字段
默认 19 项：贴文ID、贴文信息、贴文信息翻译、贴文链接、贴文原始链接、贴文时间、贴文多媒体、贴文点赞量、贴文评论量、贴文分享量、贴文类型、转贴/原创、专页ID-链接里的ID、贴文OCR、贴文OCR文本翻译、是否为改贴、图片链接、音频文本、文本翻译。
另有可选作者信息、播放量、状态、错误、抓取时间等字段。存在字段不代表该贴文一定有对应数据。
“贴文多媒体”生成 IMAGE 预览公式，Drive 图片使用 thumbnail 链接；只有映射到 J 列时，J 列才是该字段。
私有图片不一定能被 Sheets 的 IMAGE 读取。公开访问必须由用户明确选择，并先确认有权公开，不能为显示图片盲目公开私密内容。
外部文本会转义可能被当成公式的内容；软件自己生成的图片公式单独处理。

六、增量、断点、覆盖
非“覆盖重抓”模式下，先看抓取日志列（如 AK），有记录就跳过；无记录再按选项检查写入开始列已有数据，两处均无数据才采集。
“覆盖重抓”绕过相应跳过判断，只跑新增数据时不要选它。日志列不要与业务字段列重叠。
恢复运行受已保存断点、行范围、跳过策略共同影响，重跑前检查这些设置。

七、轮询、并发与运行控制
项目可选择多个 Facebook 账号，单路执行也可轮询；并发用于同时处理多行，仍按账号调度规则分配。
轮询不能保证账号不掉线，也不能用来违反平台规则或规避封禁；出现验证、限流时先暂停并处理。避免不同电脑同时使用相同浏览器配置。
支持暂停、恢复、停止。第三方网络请求或浏览器操作可能要等待当前步骤退出/超时，不能保证瞬时停止。
本版已知并发音频回退可能混读其他任务的转录结果，尚未改变该容错逻辑。音频任务建议暂用 1 路并核对结果。

八、图片、OCR、语音和翻译
OCR 主要使用 Tesseract 与语言模型。英语、葡语、阿拉伯语、简体中文、斯瓦西里语、法语等按需安装；马达加斯加语使用通用 Latin 模型，并非专用语言模型。
图片未加载、文字太小/模糊/倾斜、复杂背景或语言模型不匹配都会造成空识别；先检查是否实际取得图片，再排查识别。
音频先下载/提取，再识别和翻译。转录成功不等于翻译成功；Groq/Gemini 等服务需要有效密钥、模型权限和可用额度。
支持配置多个 API 密钥，调用逻辑轮询并处理限额；同组织/项目的密钥可能共享额度，数量增加不代表配额增加。
在线处理会把相关文本、图片或音频提交给所选服务方，使用前须确认数据隐私和授权。

九、任务、日志与故障排查
支持手动及定时任务；软件和电脑需保持运行，退出或休眠不保证计划任务执行。
运行页显示当前行、成功/失败/跳过数、阶段日志和历史记录。卡住时记录版本号、行号、最后阶段日志，检查登录、网络、组件和配额，不要反复启动重复任务。
组件失败看具体安装日志；IMAGE 空白看链接与权限；OCR 空白看图片与语言包；翻译空白看原文是否识别成功和 API 状态。
共享日志前去掉密钥、Cookie、授权文件和私密贴文内容。

十、升级、备份与加密
本版更新源为当前个人仓库，Mac 提供对应芯片的 DMG 手动覆盖安装。旧版本若仍指向组织仓库，需要从个人仓库手动安装本版一次。
升级前退出软件，妥善备份 ~/Library/Application Support/FBPostCollector；备份含敏感信息，不要公开上传。
新版本将支持的旧明文凭据迁移为钥匙串主密钥保护的密文，钥匙串不可用会报错，不回退明文。
请在原电脑原系统账号升级。仅复制数据库到其他电脑无法解密授权；推荐导入项目配置后重新授权。
旧版不能直接使用已迁移的凭据，回退需升级前的受保护备份。不要随意删除钥匙串密钥。
贴文文本、日志、Chrome 会话、外部原始授权文件和历史备份不等于全部加密；安全审核报告由开发者在本地保留，不公开发布。

Windows 补充说明
本 Release 同时提供 Windows 64 位 Setup.exe、MSI 和 ZIP，优先使用 Setup.exe；主程序包含 Python，语音识别组件另行安装。
Windows 数据目录是 %APPDATA%\FBPostCollector，主密钥由当前 Windows 用户的凭据管理器保护。升级前退出并备份，跨电脑导入项目后重新授权。
Windows 使用任务栏托盘图标退出；不需要 Homebrew，按环境检测页面安装组件。未使用 Authenticode 正式签名，系统可能提示未知发布者，请核实下载来源与摘要。
